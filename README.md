# 芯智育才：8051微控制器课程教学平台

线上地址：https://sunyancai.top

芯智育才用于组织微控制器课程中的知识学习、测验、仿真实验、学习任务与教师复核。当前竞赛环境由服务端标识为 `DEMO`，种子账号和演示学习记录不代表真实教学成效。

## 当前功能

| 模块 | 已实现内容 | 证据边界 |
|---|---|---|
| 知识图谱 | 279个课程节点、先修关系、学习资源和实验关联 | 节点访问不等同于知识掌握 |
| 在线测验 | 303道课程题目、服务端作答记录和知识点得分 | 普通重复作答不包装为受控前后测 |
| 仿真实验 | 13个实验与项目任务，包括`exp02`与`proj04` | 网页仿真不等同于真实硬件测试；项目模板不等同于学生成果 |
| 学习任务 | 教师按班级或学生布置主题化步骤，学生按完成规则执行 | 完成状态以服务端记录为准 |
| 教师复核 | 任务、测验、实验、数据身份与证据不足状态 | 演示数据持续标识为演示数据 |
| AI辅助 | 课程检索、可选DeepSeek生成、本地回退和8051静态诊断 | 未进行模型微调；AI不改变评分或教师评价 |

“3.1 寻址方式”是当前样板课，步骤为：图谱定位—动画学习—专项测评—薄弱点补学—`exp02`仿真实践—再次测评。

## 技术栈

- Next.js 15.5.21、React 18、TypeScript；
- Tailwind CSS、ShadCN/UI；
- PostgreSQL、Prisma ORM；
- JWT、bcrypt、服务端角色与班级范围校验；
- Vercel生产部署。

## 本地运行

1. 安装Node.js与项目依赖：`npm install`；
2. 根据`.env.example`配置数据库、JWT和可选DeepSeek变量；
3. 生成Prisma客户端：`npm run db:generate`；
4. 启动开发环境：`npm run dev`。

数据库初始化或种子写入会改变数据，仅应在明确的开发或演示数据库中执行。
