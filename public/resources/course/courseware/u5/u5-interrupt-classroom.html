步 0 · 初始态：PC 停在 LCALL，堆栈空槽，SP＝07H。
教学口径：80C51；LCALL 先压 PCL（低）再压 PCH（高）；弹出相反。RETI 还要清内部优先级状态触发器（与普通 RET 的差别），本动画只拆堆栈恢复 PC 这一段。
电平触发 vs 边沿触发（IT0／IT1）
外中断怎么「认一次请求」：低电平一直按着算，还是只认 1→0 那一下。对照课件第 10–12 页；位号按 80C51：IT0＝TCON.0，IT1＝TCON.2（复位后 TCON＝00H，默认电平）。

低电平触发 · IT0＝0（开关）

保持闭合
IE00跟随引脚
开关一直打到低＝请求一直在。CPU 响应后，若外部仍为低，硬件还会把请求维持／再次置上，服务结束还可能再进——必须先撤掉低电平再 RETI。
清零：电平方式下 IE0／IE1 不由响应自动清掉，跟引脚走。

下降沿触发 · IT0＝1（按钮）

点一下
IE00锁存沿
只认高→低那一下，像门铃「叮」一声。IE0／IE1 在采到下降沿时置 1 锁存；CPU 响应、进入服务时由硬件自动清 0。按住不放也不会因为「一直低」而反复进（本次边沿已清）。
IT 位怎么写：IT0（TCON.0）、IT1（TCON.2）——写 0＝低电平触发，写 1＝下降沿触发。上电／复位默认 0（电平）。
会不会丢请求：边沿方式下，只要下降沿已被采样并锁进 IEx，即使当时 CPU 正在打更高优先级，一般也会等 RETI 后再来——已锁存的沿不白丢。真正容易丢的是脉宽太窄（短于约 1 个机器周期），两次采样都没看见 1→0。
电平方式则相反：低必须保持到被响应；若高级占着时你把低撤了，这次请求就没了。
口诀：电平像开关——按住才算、松了就没、松晚了会再进；边沿像按钮——叮一声锁进 IE0，响应硬件清，窄脉冲才易漏。

机理：采样 · 锁存 · 清零时间线 主讲 · 门铃类比为辅
两种方式都看 INT0/INT1 引脚（INT0 = P3.2）。差别不在“谁来叫”，而在 怎么认请求、IE0 谁清、RETI 后会不会再进。依据：课件第 10–12 页；教材约 P94–95 表 5-1。

IT=1 下降沿（下沿）触发

  • 检测 1→0；检测到后把请求 锁存进 IE0。
  • CPU 应答时 硬件清 IE0；本次按住只算一次。
  • 要再进中断，须引脚回到高，再来一次下降沿。

IT=0 低电平触发

  • 请求 跟随引脚低电平；低要保持到被应答。
  • IE0 不由硬件自动清；电平撤掉后请求才消失。
  • 若 RETI 时仍为低 → 立即再进入（课件第 11 页）。
选型：按键点一下只加 1选下降沿 → SETB IT0。按住也不重复计数。
选型：持续故障要一直伺候选低电平；ISR 里必须先消除故障条件（或屏蔽），再 RETI，否则会连进。
门铃类比可作辅记：边沿≈按一下门铃记下“有人来过”；电平≈按住不松门铃一直响。主线仍用上图：采样 / 锁存 / 清零 / RETI 再进风险。
依据：课件第 10–12 页；教材表 5-1（P94）。电平方式下，低电平要保持到被响应，并在服务结束前撤掉，否则返回后再次进入中断（课件第 11 页）。

    ⑭ 定时器 / 计数器装值计算 · 考试要点（80C51）
    依据课件第32页起定时器部分 + Intel「16-bit timer/counter」溢出置 TF。芯片口径：80C51（12 振荡周期 = 1 机器周期）。公式用等宽突出，先背方式1，再迁到方式0/2。

    方式1 · 16位定时（最常考）

    初值 = 65536 − 要定时的时间 / 机器周期 机器周期 = 12 × 振荡周期
    TH+TL 拼成 16 位加 1；从初值加到 FFFFH 再溢出 → TF 置 1。最大约 65536 个机器周期。
    课上死例子（写死）
    晶振 12MHz → 振荡周期 1/12 μs → 机器周期 = 1μs。
    要定时 1ms = 1000 个机器周期：
    初值 = 65536 − 1000 = 64536 = FC18H
    → TH = FCH，TL = 18H。
    小计算器 · 点一下算出 TH/TL（方式1）
    初值 = 64536 = FC18H → TH=FCH TL=18H
    机器周期 = 12 / 晶振(MHz) μs。上例默认已填：12MHz、1000μs。

    计数方式 · C/T=1（方式1）

    TMOD 里 C/T=1：TL 每来一个外部脉冲加 1（不是机器周期）。要计 N 个脉冲：
    初值 = 65536 − N
    例：计 200 次 → 65536−200 = 65336 = FF38H → TH=FFH，TL=38H。

    方式0 · 13位

    计数范围 0～8191（213−1）。N = 要计的机器周期数（定时）或外部脉冲数（计数）：
    初值 = 8192 − N
    装入时仍写 TH/TL，但只用到 13 位有效位（TH 高 8 位 + TL 低 5 位）。

    方式2 · 8位自动重装

    真正在跑的是 TL；TH 存重装值。TL 从初值加到溢出后，硬件把 TH 再装回 TL——改时间只改 TH/TL 初值，溢出后不用软件重装。
    初值 = 256 − N　　（N ≤ 256）
    课上强调：方式2 适合「固定短间隔反复溢出」（如波特率、短节拍），不必在 ISR 里再 MOV 初值。
    练习 · 先算再看答案
    三道都是考试口径；点「看答案」展开。建议先自己写 TH/TL。
    题1　晶振 12MHz，定时 500μs，求方式1 的 TH、TL。
    机器周期 1μs → 要计 500 个机器周期。
    初值 = 65536 − 500 = 65036 = FE0CH
    → TH = FEH，TL = 0CH。
    题2　晶振 12MHz，计外部脉冲 200 次（方式1，C/T=1），求初值（及 TH、TL）。
    计数与晶振无关，只论脉冲个数。
    初值 = 65536 − 200 = 65336 = FF38H
    → TH = FFH，TL = 38H。
    题3　方式2，要每 100 个机器周期溢出一次，TH=TL=？
    初值 = 256 − 100 = 156 = 9CH
    → TH = TL = 9CH（TH 作重装值，与 TL 初值相同）。
