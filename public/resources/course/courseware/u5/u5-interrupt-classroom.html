下降沿触发 · IT0＝1（按钮）

点一下
IE00锁存沿
只认高→低那一下，像门铃「叮」一声。IE0／IE1 在采到下降沿时置 1 锁存；CPU 响应、进入服务时由硬件自动清 0。按住不放也不会因为「一直低」而反复进（本次边沿已清）。
IT 位怎么写：IT0（TCON.0）、IT1（TCON.2）——写 0＝低电平触发，写 1＝下降沿触发。上电／复位默认 0（电平）。
会不会丢请求：边沿方式下，只要下降沿已被采样并锁进 IEx，即使当时 CPU 正在打更高优先级，一般也会等 RETI 后再来——已锁存的沿不白丢。真正容易丢的是脉宽太窄（短于约 1 个机器周期），两次采样都没看见 1→0。
电平方式则相反：低必须保持到被响应；若高级占着时你把低撤了，这次请求就没了。
口诀：电平像开关——按住才算、松了就没、松晚了会再进；边沿像按钮——叮一声锁进 IE0，响应硬件清，窄脉冲才易漏。

  • 检测 1→0；检测到后把请求 锁存进 IE0。

    计数方式 · C/T=1（方式1）

    TMOD 里 C/T=1：TL 每来一个外部脉冲加 1（不是机器周期）。要计 N 个脉冲：
    初值 = 65536 − N
    例：计 200 次 → 65536−200 = 65336 = FF38H → TH=FFH，TL=38H。

    方式0 · 13位

    计数范围 0～8191（213−1）。N = 要计的机器周期数（定时）或外部脉冲数（计数）：
    初值 = 8192 − N
    装入时仍写 TH/TL，但只用到 13 位有效位（TH 高 8 位 + TL 低 5 位）。

    方式2 · 8位自动重装

    真正在跑的是 TL；TH 存重装值。TL 从初值加到溢出后，硬件把 TH 再装回 TL——改时间只改 TH/TL 初值，溢出后不用软件重装。
    初值 = 256 − N　　（N ≤ 256）
    课上强调：方式2 适合「固定短间隔反复溢出」（如波特率、短节拍），不必在 ISR 里再 MOV 初值。

    B所以然 · 为什么这样

    每条：技术一句 + 设计取舍一句。点开讲透即可，不必全念。

    1为何中断响应像 LCALL 却只自动保 PC？

    技术：硬件把断点 PC 压栈并跳到向量——像做了一次 LCALL；A、PSW、DPTR 等不自动压。

    设计取舍：省硅片与时间——现场因 ISR 而异，留给程序员按需 PUSH；全自动保护会又慢又贵。

    2为何相邻入口只隔 8 字节、向量处只放 LJMP？

    技术：五源固定入口，彼此只留约 8 字节；服务程序通常更长，所以入口只跳。

    设计取舍：用极少 ROM 槽位换「一源一地址」；空间不够就 LJMP 出去，骨架清晰。

    3为何要分 IE（允不允许）和 IP（谁优先）？

    技术：IE＝总闸+分闸（能不能进）；IP＝高/低优先（谁可打断谁）。

    设计取舍：把「开关」和「排队」拆开，几个位就能调度多源，不必另做复杂仲裁器。

    4为何外中断要 IT 选下沿/电平，清零规则不同？

    技术：IT＝1 认 1→0 边沿，应答时硬件清标志；IT＝0 跟低电平，不自动清，仍低会再进。

    设计取舍：点一下只加 1 用下沿；持续故障要一直伺候用电平——一种硬件两种用法。

    5为何 TMOD 不能位寻址、须整字节？

    技术：TMOD 不在位寻址区；改方式用 MOV TMOD,#xxH，禁 SETB TMOD.0。

    设计取舍：方式字常整字节配置；位寻址留给真正要频繁置位的标志（如 IE、TCON）。

    6为何方式1 溢出必须重装？

    技术：方式1 满后从 0000H 接着数，不会自动回到你写的初值。

    设计取舍：通用 16 位计数器省硬件；要固定周期就在 ISR 里重装——方式2 才是「自动重装」的取舍。

    7为何返回必须用 RETI 不能只用 RET？

    技术：RETI 弹 PC 并清当前优先级触发器；RET 只弹 PC。

    设计取舍：有了优先级锁，才能嵌套又不会乱；错用 RET，高级/同级响应会卡住。

    必会重点（9 · 点开看纠错一句）
    1查询 vs 中断：空等 vs 被叫
    查询：CPU 反复问外设，空等多。中断：外设来叫，主程序可继续干活。
    设计动机一句：别让 CPU 空等 Delay，让硬件来叫。
    2五源及入口：INT0=0003H…
    INT0 0003H、T0 000BH、INT1 0013H、T1 001BH、串口 0023H；各隔 8 字节。
    3TCON：IT/IE 触发与清零
    外中断：IT 选下沿/电平；IE0/IE1 是请求标志。串口 RI/TI 软件清。
    4IE 拼字节：例 → 8AH
    先合总闸 EA，再合分闸。允许定时器中断例：EA+ET1+ET0 → 8AH。
    5硬件只保 PC；A/PSW 自 PUSH；RETI
    像 LCALL 只压断点。现场（A/PSW 等）自己压；结尾必须 RETI（不是 RET）。
    6入口 8 字节 → LJMP；程序四块
    向量处只放跳转；服务程序放后面。四块：初始化 / 向量 LJMP / ISR / 主循环。
    7TMOD 整字节写；禁 SETB TMOD.0
    TMOD 不能位寻址。正确：MOV TMOD,#01H。错误：SETB TMOD.0。
    8方式1 初值：6MHz→FE0CH
    X=65536−N。SSOT 锁：6MHz、1ms → FE0CH；12MHz、1ms → FC18H。勿混用。
    9方式1 溢出须重装
    装一次≠永远 1ms。溢出后从 0000H 接着数；ISR 里重装 TH/TL。
