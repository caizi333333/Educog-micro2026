⑭ 定时器 / 计数器装值计算 · 考试要点（80C51）
依据课件第32页起定时器部分 + Intel「16-bit timer/counter」溢出置 TF。芯片口径：80C51（12 振荡周期 = 1 机器周期）。公式用等宽突出，先背方式1，再迁到方式0/2。 · 子知识点：÷256 拆字节 #hex-split · 投影单文件
子知识点16 位数 ÷256 / mod 256 → TH / TL

所以然：256 = 28。对任意 16 位初值 X，TH = X÷256（取整）、TL = X mod 256，与「切高 8 位 / 低 8 位」是同一件事；合写即 X = TH×256 + TL。

课上死例子 · 12MHz · 1ms

初值 X = 64536
TH = 64536÷256 = 252 = FCH
TL = 64536 mod 256 = 24 = 18H
合写 → FC18H
一圈边界：65535 = FFFFH；65536 = 10000H（溢出一圈）。方式1：初值 = 65536 − N。
芯片口径 80C51：方式1 用满 16 位计数器；装值就是把这 16 位拆进 TH/TL。
手算演示 · 输入十进制初值 X
X = 64536 → TH=FCH（252）　TL=18H（24）　合写 FC18H
验算：252×256 + 24 = 64536。与位切高8/低8相同。

方式1 · 16位定时（最常考）

初值 = 65536 − 要定时的时间 / 机器周期 机器周期 = 12 × 振荡周期
TH+TL 拼成 16 位加 1；从初值加到 FFFFH 再溢出 → TF 置 1。最大约 65536 个机器周期。
课上死例子（写死）
晶振 12MHz → 振荡周期 1/12 μs → 机器周期 = 1μs。
要定时 1ms = 1000 个机器周期：
初值 = 65536 − 1000 = 64536 = FC18H
→ TH = FCH，TL = 18H。
小计算器 · 点一下算出 TH/TL（方式1）
初值 = 64536 = FC18H → TH=FCH TL=18H
机器周期 = 12 / 晶振(MHz) μs。上例默认已填：12MHz、1000μs。

计数方式 · C/T=1（方式1）

TMOD 里 C/T=1：TL 每来一个外部脉冲加 1（不是机器周期）。要计 N 个脉冲：
初值 = 65536 − N
例：计 200 次 → 65536−200 = 65336 = FF38H → TH=FFH，TL=38H。

方式0 · 13位

计数范围 0～8191（213−1）。N = 要计的机器周期数（定时）或外部脉冲数（计数）：
初值 = 8192 − N
装入时仍写 TH/TL，但只用到 13 位有效位（TH 高 8 位 + TL 低 5 位）。

方式2 · 8位自动重装

真正在跑的是 TL；TH 存重装值。TL 从初值加到溢出后，硬件把 TH 再装回 TL——改时间只改 TH/TL 初值，溢出后不用软件重装。
初值 = 256 − N　　（N ≤ 256）
课上强调：方式2 适合「固定短间隔反复溢出」（如波特率、短节拍），不必在 ISR 里再 MOV 初值。
练习 · 先算再看答案
三道都是考试口径；点「看答案」展开。建议先自己写 TH/TL。
题1　晶振 12MHz，定时 500μs，求方式1 的 TH、TL。
机器周期 1μs → 要计 500 个机器周期。
初值 = 65536 − 500 = 65036 = FE0CH
→ TH = FEH，TL = 0CH。
题2　晶振 12MHz，计外部脉冲 200 次（方式1，C/T=1），求初值（及 TH、TL）。
计数与晶振无关，只论脉冲个数。
初值 = 65536 − 200 = 65336 = FF38H
→ TH = FFH，TL = 38H。
题3　方式2，要每 100 个机器周期溢出一次，TH=TL=？
初值 = 256 − 100 = 156 = 9CH
→ TH = TL = 9CH（TH 作重装值，与 TL 初值相同）。

用途直觉 · 测外部高电平脉宽

先软件 TR=1（门栓拉开），外面变高 → 窗口打开开始计；变低 → 窗口关停。读出的 TH/TL 就是这段高电平里走过的机器周期数（C/T=0 时）。对照⑮例5-8。

和 C/T 别混

C/T=0：每个机器周期尝试加 1（定时）。C/T=1：T0/T1 脚来脉冲才加（计数）。两者都还要过 GATE 这扇门——GATE 不决定「数什么」，只决定「许不许加」。
嵌进技术点 · 有限资源干大事：80C51 不专设「测脉宽」外设——TMOD 里 1 位 GATE，再复用已有 INT 脚，就给现有 TH/TL 加了一扇门，组合出测宽能力。「该开才开」对应门控条件；工程师守的是条件边界，不是口号。 同语气见 #rev-sz。

【例5-1】IE 拼字节 · 课件第15页

允许片内定时器/计数器中断，禁止其他中断。写出对 IE 的设置指令。

寄存器IE：需置位 EA、ET1、ET0 → 二进制 10001010B = 8AH
位说明EA=1 总允许；ET1=1、ET0=1；EX0/EX1/ES=0；保留位按 0
MOV IE,#8AH    ; EA + ET1 + ET0
  1. 先开总闸 EA，再开分闸 ET0、ET1。
  2. 片外与串口分闸保持 0，禁止其他源。
  3. 一次写字节比逐位 SETB 更适合考试拼码。
  4. 页签⑤有交互拼字节；本题答案固定为 MOV IE,#8AH。

【例5-2】IP 优先级 · 课件第20页

使片外中断为高优先级，片内中断为低优先级。写出对 IP 的设置。

寄存器IP：PX0=1、PX1=1 → 05H
位说明PX0、PX1 高；PT0/PT1/PS 低（0）
MOV IP,#05H    ; PX0 + PX1
  1. 软件优先级看 IP 对应位：1=高，0=低。
  2. 两路外部中断都置高 → PX0|PX1 = 05H。
  3. 同级内仍按自然序 INT0>T0>INT1>T1>串口。
  4. 页签⑥有嵌套时间线演示，可对照。

【例5-4】T0 方式1 定时 1ms @6MHz · 课件第45页

晶振 6MHz，T0 方式1，定时 1ms。求 TH0、TL0。

机器周期12/6 = 2μs；1ms = 1000μs → N = 1000/2 = 500
初值65536 − 500 = 65036 = FE0CH → TH0=FEH，TL0=0CH
MOV TL0,#(65536-500) MOD 256
MOV TH0,#(65536-500)/256
; 等价：MOV TH0,#0FEH / MOV TL0,#0CH
  1. 先算机器周期，再算要计的机器周期数 N。
  2. 方式1：初值 = 65536 − N。
  3. 拆成 TH/TL；也可用汇编表达式写 MOD/DIV。

【例5-8】GATE=1 测 INT0 正脉冲宽 · 课件第59–60页

B所以然 · 为什么这样

每条：技术一句 + 设计取舍一句。点开讲透即可，不必全念。

1为何中断响应像 LCALL 却只自动保 PC？

技术：硬件把断点 PC 压栈并跳到向量——像做了一次 LCALL；A、PSW、DPTR 等不自动压。

设计取舍：省硅片与时间——现场因 ISR 而异，留给程序员按需 PUSH；全自动保护会又慢又贵。

2为何相邻入口只隔 8 字节、向量处只放 LJMP？

技术：五源固定入口，彼此只留约 8 字节；服务程序通常更长，所以入口只跳。

设计取舍：用极少 ROM 槽位换「一源一地址」；空间不够就 LJMP 出去，骨架清晰。

3为何要分 IE（允不允许）和 IP（谁优先）？

技术：IE＝总闸+分闸（能不能进）；IP＝高/低优先（谁可打断谁）。

设计取舍：把「开关」和「排队」拆开，几个位就能调度多源，不必另做复杂仲裁器。

4为何外中断要 IT 选下沿/电平，清零规则不同？

技术：IT＝1 认 1→0 边沿，应答时硬件清标志；IT＝0 跟低电平，不自动清，仍低会再进。

设计取舍：点一下只加 1 用下沿；持续故障要一直伺候用电平——一种硬件两种用法。

5为何 TMOD 不能位寻址、须整字节？

技术：TMOD 不在位寻址区；改方式用 MOV TMOD,#xxH，禁 SETB TMOD.0。

设计取舍：方式字常整字节配置；位寻址留给真正要频繁置位的标志（如 IE、TCON）。

6为何方式1 溢出必须重装？

技术：方式1 满后从 0000H 接着数，不会自动回到你写的初值。

设计取舍：通用 16 位计数器省硬件；要固定周期就在 ISR 里重装——方式2 才是「自动重装」的取舍。

7为何返回必须用 RETI 不能只用 RET？

技术：RETI 弹 PC 并清当前优先级触发器；RET 只弹 PC。

设计取舍：有了优先级锁，才能嵌套又不会乱；错用 RET，高级/同级响应会卡住。

必会重点（9 · 点开看纠错一句）
1查询 vs 中断：空等 vs 被叫
