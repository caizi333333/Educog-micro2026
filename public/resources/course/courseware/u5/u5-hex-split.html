16 位数 ÷256 / mod 256 → TH / TL

字号 回第 3 次课 · ⑭
子知识点TH = X÷256（取整）　TL = X mod 256

所以然：256 = 28。对任意 16 位初值 X，切高 8 / 低 8 与「整除 256 + 取余」是同一件事；合写 X = TH×256 + TL。

课上死例子 · 12MHz · 1ms

初值 X = 64536
TH = 64536÷256 = 252 = FCH
TL = 64536 mod 256 = 24 = 18H
合写 → FC18H
一圈：65535 = FFFFH；65536 = 10000H。
方式1：初值 = 65536 − N。
芯片 80C51：方式1 用满 16 位；装值 = 把这 16 位拆进 TH/TL。
手算演示 · 输入十进制初值 X
X = 64536 → TH=FCH（252）　TL=18H（24）　合写 FC18H
验算：252×256 + 24 = 64536。与位切高8/低8相同。
