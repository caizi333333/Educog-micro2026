- 性能结果必须同时记录地址、部署版本、接口、并发数、持续时间、p50/p95/p99、吞吐量和错误率；
- 即时数据库健康检查不等同于历史可用率；
- 未在同一基线、同一环境和同一脚本下复测前，不发布“速度提升30%—50%”“渲染提升40%—60%”等百分比；
