# “芯智育才”平台演示脚本（8分钟内）

> 版本：2026-08-04。演示数字与页面当前口径一致；演示数据不表述为真实教学成效。

## 0:00—0:40　定位与证据身份

打开登录页，说明平台服务于微控制器课程的“教师布置—学生学习—服务端记录—教师复核”。使用申请书预留教师账号登录，首先指向页面上的“演示数据”标识。

解说要点：当前已记录的是平台过程数据；真实成绩、课堂观察、问卷和学生项目成果仍待采集，因此本演示不报告教学提升百分比。

## 0:40—2:10　教师布置“3.1 寻址方式”

进入教师页面，先指出教师主导航中的“任务回查、教学资源、教学分析”，确认不混入学生个人任务、薄弱点、个性学习和成就入口。再选择具体主题、班级或单个学生，展示系统计算的目标人数和六个任务步骤。若学生已有学习路径，展示影响说明和显式替换确认，不执行静默覆盖。

角色检查：教师账号直接访问`/tasks`时应看到“返回教学仪表板/查看推送记录”，不得出现“加入班级”，也不得读取学生个人任务列表。

六步依次为：图谱定位、动画学习、专项测评、薄弱点补学、`exp02`仿真实践、再次测评。

## 2:10—3:10　学生任务与图谱定位

切换唯一演示学生，进入任务页。先指出“演示数据”标识，再说明同名任务以独立记录号保留。打开最近一条完成回执，依次说明6个步骤、首次作答、最近一次作答、分数变化、薄弱点去留和exp02服务端回执；强调缺少任一同口径测评回执时页面只显示数据不足。随后通过深链接打开专业图谱`3.1`及七个子节点，刷新一次确认仍停留在`3.1`；再到问题图谱打开`P1.2.2`，展示“知识点补学—专项测评—exp02—再次测评”的四步入口、完成判定和“不会静默推进教师任务”的状态边界；最后在育人图谱点击第3周`KP 3.1 → S2.1/S3.1`映射。

图谱检查：先选CH1节点，再切CH3；筛选数量、画布和右侧详情须同时进入CH3，详情不得残留CH1节点。问题图谱切换类别/难度、育人图谱切换主题/章节时执行同样检查；隐藏节点不能再被点击或获得键盘焦点。`3.1`详情中的“第3周明确映射”只应出现`S2.1/S3.1`，同章内容关联不能冒充本周安排。

解说要点：专业图谱279节点定位知识，问题图谱197节点把错误继续导向补学和验证，育人图谱以6个主题、21个元素和17周显式映射承接规范与责任判断；节点访问记录表示学习过程发生，不等同于知识已经掌握。自主补弱结果由测评或实验页面保存，教师任务仍由任务页控制顺序。

## 3:10—4:10　专项测评与薄弱点

进入寻址方式专项测评，说明测评使用正式`quizId`、`chapterId`和知识点编号。提交后展示服务端返回的得分与薄弱点，再进入对应补学资源。

解说要点：AI可以解释错因，但不能改变测验判定。普通重复作答只称“首次作答/最近一次作答”，不称受控前后测。

## 4:10—5:15　`exp02`仿真实践与代码诊断

从任务页进入`exp02`，按指导运行指令系统实验，展示代码、寄存器或端口反馈与保存状态。再用一个固定错误样例演示8051静态诊断。

解说要点：网页仿真用于课前练习和过程记录，不等同于真实硬件电气测试；静态诊断只对已覆盖错误类型负责。

## 5:15—6:10　再次测评与教师复核

完成再次测评后返回教师页，从班级汇总下钻目标学生。核对任务步骤、首次与最近一次作答、`exp02`记录以及数据不足提示。

解说要点：只有预先固定前测与后测编号、对象和计分规则时，才计算教学增益。

## 6:10—6:55　AI能力边界

进入AI助教，提出课程范围内问题。说明实际流程为课程内容检索、提示约束、可选DeepSeek生成、本地回退与8051静态诊断，当前没有模型微调。

展示固定基准下载入口：50道正式题库题直接使用题干、选项或待补全代码，不附加目标知识点名称；2026年8月25日本地固定运行记录中，Recall@3为68%、全返回知识点命中率为80%、MRR为0.4453。48个静态诊断样例F1为1.00、行号定位准确率为100%。本次未调用外部生成服务，生成式指标保持待实测。截至2026年8月25日，生产站点仍提供8月3日schema v4历史记录，最终发布后应核对为schema v5且摘要一致后再展示。

## 6:55—7:35　综合项目与AI素养

打开`proj04`，说明它是平台内置综合项目任务模板，传感数据为仿真输入。展示跨专业角色、五个里程碑、提交证据和评价量规，再指出AI输出核验、隐私安全、提示设计、辅助调试边界和学术诚信要求。

解说要点：没有学生真实提交物和教师评分前，不将模板称为学生成果。

## 7:35—8:00　技术状态与收束

回到教师证据状态区，按需触发数据库即时检查。说明最终生产部署25并发500次只读请求错误率0.40%、p95为807.59毫秒，达到验收档；50并发1000次请求错误率0%、p95为747.27毫秒，仍只作容量观察。即时探测和30分钟窗口都不代表历史可用率。

最后总结：平台当前已经完成可操作的教学闭环和过程记录；真实教学成效与学生成果按既定口径继续采集。

## 录制检查

- 1280×720、25fps、H.264/AAC，总时长不超过8分钟；
- 页面、旁白、字幕和文档数字一致；
- 删除黑屏、加载等待和重复停顿；
- 全程只使用一个演示学生，不批量改变生产数据；
- 不在画面、字幕或旁白中暴露密码、令牌或密钥。
