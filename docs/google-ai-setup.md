# AI服务配置说明

> 文件名为历史兼容保留。当前平台不使用Google Gemini作为生成服务，也不需要Google AI密钥。

## 1. 当前实现

AI辅助由四部分组成：

1. 从平台课程内容中检索相关知识点与实验；
2. 在已配置且可用时调用DeepSeek生成解释；
3. 接口不可用时返回课程内置说明，不伪造在线生成；
4. 对8051代码使用确定性静态规则给出已覆盖错误的诊断提示。

平台未进行模型微调。AI内容只作解释和提示，不能直接改变测验得分、实验完成状态或教师评价。

## 2. 环境变量

根据`.env.example`配置DeepSeek变量。密钥只放在本地或部署平台的受控环境变量中，不写入仓库、截图或申报材料。

未配置密钥时，课程检索、本地回退和静态诊断仍可工作；生成式指标保持“尚未完成实测”。本项目不因竞赛演示自动充值或写入推测结果。

## 3. 验证

1. 在AI助教页面提出一个课程范围内问题，核对是否标明课程依据或回退状态；
2. 提出超出课程范围的问题，核对是否提示适用范围；
3. 提交固定8051错误样例，核对错误类型和行号；
4. 执行固定基准，保存模型、日期、代码版本、样本量、公式和结果JSON。

登录后可下载的基准记录位于`public/ai-benchmark.json`。检索部分直接使用正式题库题干与选项，不附加目标知识点名称；只有JSON中存在实际运行记录的指标才可进入申报材料。

## 4. 常见失败与处理

| 状态 | 页面处理 | 证据处理 |
|---|---|---|
| 未配置密钥 | 使用课程检索、本地回退或静态诊断 | 生成式指标标“待实测” |
| 密钥无效或无额度 | 显示受控错误并回退 | 不充值、不填写推测值 |
| 网络超时 | 允许重试并保留用户输入 | 记录失败，不计入成功样本 |
| 内容依据不足 | 明确提示人工或教材复核 | 不将回答计为通过 |
