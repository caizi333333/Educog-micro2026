# 芯智育才平台说明（证据口径版）

> 版本：2026-08-04
>
> 线上地址：https://sunyancai.top
>
> 当前数据身份：`DEMO`（演示数据）

## 1. 平台定位

芯智育才面向微控制器课程的教学组织与学习支持。当前平台把知识图谱、测验、仿真实验、学习任务和教师复核放在同一课程环境中，重点验证“教师布置—学生学习—服务端记录—教师复核”能否连续运行。

平台现有过程记录可以说明功能是否被使用、步骤是否完成；不能据此直接推出学习成绩提升、课堂教学效果或学生工程能力提升。未完成真实班级同口径采集的指标统一标为“待采集”或“数据不足”。

## 3. “寻址方式”样板闭环

“3.1 寻址方式”先由三类图谱共同定位：专业节点`3.1`及七个子节点回答“学什么”；问题节点`P1.2`及四类典型错误回答“错在哪里”；第3周映射显式连接`S2.1`严谨态度与`S3.1`规范意识，回答“怎样形成可检查的工程规范”。专业图谱只把教学周映射表中的节点标作“明确映射”，同章或共享知识点不自动算入本周安排。具体寻址错误另提供“对应知识点补学—专项测评—exp02—同口径再次测评”的自主补弱顺序、完成判定和状态边界。随后按以下六步组织：

1. 图谱定位：识别 `3.1` 及子节点和先修关系；
2. 动画学习：查看课程资源并记录学习事件；
3. 专项测评：使用正式 `quizId`、`chapterId` 和知识点编号；
4. 薄弱点补学：按服务端测评结果推荐真实图谱资源；
5. 仿真实践：进入 `exp02` 指令系统实验；
6. 再次测评：记录同一测验的最近一次作答，供教师复核变化。

每一步均说明目的、完成条件、当前状态和下一入口。刷新、返回或重新登录后，任务状态以服务端记录恢复；AI解释仅作为辅助提示。

知识图谱切换章节时，右侧详情只保留当前章节点；问题图谱切换类别或难度、思政图谱切换章节或主题时也使用同一规则。原选中节点不可见时自动选择当前有效节点，无结果时清空详情；隐藏节点不再响应鼠标点击或键盘焦点。`chapter + node`深链接在首次进入、刷新和返回后保持目标子节点。问题图谱自身不直接修改成绩、实验完成或任务进度；自主补弱由目标页面保存结果，教师任务仍从任务页按解锁顺序进入。移动端关闭的目录抽屉从可访问性树中移除。

## 4. 技术实现

| 层 | 当前技术 |
|---|---|
| 页面与接口 | Next.js 15.5.21、React 18、TypeScript、App Router/API Routes |
| 样式与组件 | Tailwind CSS、ShadCN/UI |
| 数据 | PostgreSQL、Prisma ORM |
| 身份与权限 | JWT、bcrypt、服务端角色和班级范围校验 |
| 部署 | Vercel生产环境 |

本项目没有使用Redis作为当前必需运行组件，也不将网页仿真描述为真实硬件的1:1电气模型。更完整的实体、权限和接口说明见 `docs/platform-architecture-and-features.md`。

## 5. 当前可发布的测试结果

- 本地检索与8051静态诊断已有固定基准运行记录，样本、公式、日期和代码版本随JSON结果保存；
- 生成式问答只有在现有DeepSeek密钥与额度可用并实际运行后才发布指标；
- 性能结果仅对记录的接口、并发档位和测试窗口负责；即时数据库探测不等同于历史可用率；
- 自动化测试、类型检查和生产构建用于证明当前代码可运行，不等同于教学成效证明。
- 2026-08-04图谱专项回归后，全量回归为67个测试套件、1326项通过，53项按既有配置跳过；类型检查和生产构建通过。279个专业节点、197个问题节点、27个思政节点及17周映射的父级、知识点和显式目标引用均可解析。部署`dpl_CQn4p7VnTgM2s1338wFTfPRt56HR`为`READY`；线上已复核3.1深链接与刷新恢复、明确育人映射、寻址问题四步入口、普通问题章节入口及390×844无横向溢出。该结论仅对应本次代码、部署和页面快照。
- 2026-08-04学生结果回执回归后，全量回归为67个测试套件、1327项通过，53项按既有配置跳过；类型检查和生产构建通过。部署`dpl_7zzbgo9gYFXWiRnxSfrEBPmYEjoo`为`READY`并绑定`sunyancai.top`。线上任务页显示服务端`DEMO`身份；同名任务以独立记录号区分；每条完成任务仅在任务号、`quiz-ch3-addressing`和`initial/retest`阶段同时匹配时计算首次/最近一次作答变化，并显示薄弱点去留和exp02回执。缺任一回执时显示数据不足，不生成变化值。

登录后可下载的基准记录：`public/ai-benchmark.json`。2026-08-25本地固定运行使用50道正式题库题，未向查询附加目标知识点名称；Recall@3为68%、全返回知识点命中率为80%、MRR为0.4453。该结果只说明当前固定样本下的检索表现，不等同于开放问答正确率。截至2026-08-25，生产站点仍是2026-08-03的schema v4历史记录；最终发布后需复核线上文件已更新为schema v5。
