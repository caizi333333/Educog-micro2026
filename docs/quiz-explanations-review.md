# 8051 题库解析补充：教师复核记录

基线：`0c6e61c`（`origin/release/2026-09-20-production`）。仅补充原来缺少的解析，不修改题干、选项、答案、编号或原有解析。所有新增解析均为 AI 辅助草拟，待教师复核；不代表已获教师审定。

默认技术口径：标准 8051、经典 12T 内核；涉及波特率时按题设晶振及复位默认 SMOD=0。器件扩展功能、引脚接线和显示有效电平须以题设为准，不以猜测的接线替题目补全前提。

## 暂不补解析的题目

这些题目仍保留原样，不能用新增解析替错误答案背书。建议教师明确题设或修订答案后另行处理。

| ID | 题干 | 存储答案 | 疑点 |
| --- | --- | --- | --- |
| 49 | 访问内部RAM地址为60H的单元，属于哪种寻址方式？ | 直接寻址 | 只有目标地址，没有指令形式。`MOV A,60H` 是直接寻址，而R0=60H时 `MOV A,@R0` 同样访问该单元，却是间接寻址。 |
| 86 | 如果IP寄存器的值为00001001B，哪个中断的优先级最高？ | 外部中断0 (IE0) | PX0、PT1同时置1，INT0与T1同为高优先级；只有补充“同级请求同时待响应时的查询次序”才能唯一选INT0。 |
| 110 | 补全代码，启动ADC0809的模拟通道0转换。 | 08H | 缺少ALE连接和地址锁存过程，不能确认通道0已选中；`MOV P2,#08H` 还把作为EOC输入的P2.4锁存器写0，准双向口无法正常读入该信号。应先明确电路与完整启动时序。 |
| 130 | 补全代码，显示8位数码管的第4位（从左数），其他位熄灭。 | 0F7H | F7H只使bit3为0，但未说明位选是否低有效、P2各位与数码管左右顺序的对应关系。缺少接线图，不能唯一确定常量。 |
| 132 | 在设计一个数字温度计系统时，需要用到哪些8051的功能模块？ | ADC + 数码管显示 + 定时器 + 串口 | 未要求串口通信或指定模拟温度传感器，串口不是温度计必需模块；数字温度传感器方案也可能不需要ADC。 |
| 149 | 补全代码，检测P1.0是否为低电平。 | JB | 题干说检测低电平，但代码目标为HIGH_LEVEL且注释说“如果P1.0=1则跳转”。JB符合代码注释，JNB才是低电平条件跳转，应统一题干与分支意图。 |
| 152 | 补全代码，实现累加器A的内容左移一位。 | RL | RL是循环左移，A.7回到A.0，不是低位补0的逻辑左移；例如80H经RL变为01H而非00H。题干未写“循环”或限制A.7=0。 |
| 165 | 当同时有多个同优先级中断请求时，CPU如何处理？ | 按默认优先级顺序 | 另一个选项“按中断号顺序”在标准8051中也可表示同一固定查询次序，单选选项重叠；宜明确说硬件查询次序，避免与IP设置的优先级混淆。 |
| 167 | 补全代码，显示数字"8"的段码。 | 7F | 未说明共阴极/共阳极和段线位序。7FH仅在高有效、低7位对应a至g且小数点关闭等约定下成立。 |
| 170 | 在LED点阵显示中，行扫描和列扫描的作用是什么？ | 行选择，列控制亮灭 | 逐行扫描可采用此分工，逐列扫描则相反；题干未限定扫描方式，另一个选项“列选择，行控制亮灭”也可成立。 |
| 172 | 补全代码，扫描矩阵键盘的第一行。 | FE | 未说明第一行连接哪个引脚。FEH拉低P1.0，而题库102的例子把首行放在P1.4，需为本题补充独立接线约定。 |
| 184 | 补全代码，等待ADC转换完成。 | JB | ADC0809的EOC在启动后的短暂延迟及空闲时也可能为高；仅轮询高电平可能立即误读旧数据，应先确认EOC变低，再等待其升高，或明确此前已完成该握手。 |
| 186 | 设计一个数字时钟系统，主要需要哪些功能模块？ | 定时器+数码管+键盘+存储器 | 未规定校时方式、掉电保存等需求，也未区分片内RAM与外扩存储；无法唯一确定是否需要独立存储模块，且“所有功能模块”选项含义不清。 |
| 194 | 补全代码，实现CRC校验计算。 | RL | 片段只有异或和循环左移，没有给出生成多项式、逐位/逐字节迭代及反馈异或，不能据此实现一般CRC。RL虽符合注释“循环左移”，却不足以支撑题干所称CRC。 |
| 203 | 波特率的定义是什么？ | 每秒传输的位数（包括起止位） | 严格定义是每秒码元数；仅二进制、一位一码元的UART等情形才与bit/s数值相同。应在题干限定二进制UART，或将术语改为线路比特率。 |
| 244 | ADC0809 一次可采集的模拟通道数是？ | 8 | ADC0809有8路可选模拟输入，但只有一个ADC，一次转换仅转换所选的一路；“一次”若指同时采样或单次转换则答案应为1，应改问可选择的输入通道总数。 |
| 260 | 时钟电路中，与晶振并联的两个微调电容的典型取值约为？ | 30pF | 30pF可作为常见示例值，但连接描述错误：两只负载电容分别由晶振两端接地，并非分别直接跨接晶振两端。实际值还取决于晶体负载电容与杂散电容。 |
